3. 向量化流水线

双缓冲并行架构：I/O 线程池 (io_workers=8) 加载图片 → GPU 批量推理 (batch_size=512) 并行执行，预加载掩盖 I/O 延迟。

[I/O Threads] → 加载帧图片 (PIL) → 预处理 → 加入输入队列 ↓ [Main Thread] → 从队列取 batch → GPU 推理 → 特征归一化 → 加入输出队列 ↓ [Writer Thread] → 从队列取特征 → AsyncLanceWriter → 落盘

4. FP16 全链路 (v2026.06)

阶段精度改动
模型权重FP16model.half()
推理输出FP16已删除 .float() 强制转 FP32
Lance 存储FP16.astype(np.float16)
搜索加载FP16无条件 torch.float16 (已删条件分支)
效果：Lance 文件减半 (768维×2字节)、GPU 显存减半、前端 FP16 开关已移除

5. 场景检测

SceneBoundaryDetector.find_scene_boundaries()

  1. 计算相邻帧向量的余弦相似度
  2. 相似度 < cosine_similarity_threshold (默认 0.82) → 场景边界
  3. localmax_order=1 局部极大值检测去噪声
  4. 场景帧数 < min_scene_length (默认 7) → 与相邻最近场景合并

每个场景保留 3 帧特征：首帧、中间帧、尾帧，用于后续搜索时提高召回。
