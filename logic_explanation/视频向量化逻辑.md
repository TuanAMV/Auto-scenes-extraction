# 视频向量化逻辑（Indexer + P模式）

更新时间：2026-02-13  
代码依据：`Cut_DetectScene/indexer_app.py`、`Cut_DetectScene/pipeline_app.py`

## 1. 视频向量化入口（`indexer_app.py`）

### 1.1 入口链路

1. 启动脚本执行 `main()`（`Cut_DetectScene/indexer_app.py:19`）。
2. 先导入向量化核心函数：
   - `create_video_index`
   - `batch_create_video_index`
3. 导入失败时直接 `sys.exit(1)`（`Cut_DetectScene/indexer_app.py:13-16`）。

### 1.2 执行步骤

1. 在 `main()` 内定义输入/输出目录与 `PARAMETERS`（`Cut_DetectScene/indexer_app.py:27-85`）。
2. 检查 `INPUT_DIRECTORY` 是否存在，不存在直接退出（`Cut_DetectScene/indexer_app.py:93-95`）。
3. 创建输出目录（`Cut_DetectScene/indexer_app.py:98`）。
4. 自动判断输入模式（`Cut_DetectScene/indexer_app.py:100-104`）：
   - 当前目录含视频文件 -> 单目录索引模式
   - 当前目录含子文件夹 -> 批量子目录索引模式
5. 分支调用：
   - 单目录：`create_video_index([INPUT_DIRECTORY], OUTPUT_DIRECTORY, **PARAMETERS)`（`Cut_DetectScene/indexer_app.py:107-111`）
   - 批量目录：`batch_create_video_index(INPUT_DIRECTORY, OUTPUT_DIRECTORY, **PARAMETERS)`（`Cut_DetectScene/indexer_app.py:115-119`）
6. 按成功状态返回退出码：成功 `0`，失败 `1`（`Cut_DetectScene/indexer_app.py:130`）。

### 1.3 参数映射（`PARAMETERS`）

| 参数 | 当前默认值 | 作用 |
| --- | --- | --- |
| `model_name` | `openai-clip-vit-large-patch14` | 向量模型名（可自动从 models 目录解析） |
| `model_type` | `auto` | 模型类型自动检测（clip/fgclip2） |
| `truncate_dim` | `None` | 向量截断维度 |
| `output_resolution` | `'256'` | 抽帧分辨率（短边） |
| `batch_size` | `512` | 推理批处理大小 |
| `workers` | `2` | 写入线程数，写入pkl |
| `io_workers` | `8` | I/O 并发线程数，用于读取帧图片进入PIL |
| `cosine_similarity_threshold` | `0.85` | 场景切换相似度阈值 |
| `brightness_threshold` | `15` | 黑场判定亮度阈值 |
| `black_pixel_ratio` | `98` | 黑像素占比阈值 |
| `sample_interval` | `3` | 抽样间隔 |
| `min_scene_length` | `7` | 最小场景长度 |
| `localmax_order` | `1` | 局部极大值窗口 |
| `resume_processing` | `False` | 是否增量处理 |
