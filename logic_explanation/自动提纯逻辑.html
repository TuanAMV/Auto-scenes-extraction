2. Prompt 生成

从 logic_keywords.json 读取 4 大类模板，每类独立生成 prompt (非笛卡尔积)：

类别模板生成 prompt 数
主体一张以{主体}为主体的动画风格插画~192
动作一张{生物}在{动作}的... + 一张{物体}在{物理运动}的...~12,224
场景一张以{所有场景}为背景的...~48
情绪一张有{所有情绪}氛围的...~37
合计~12,500
使用 use_chinese=False 时走英文模板 + 英文标签值，use_chinese=True 走中文。FG-CLIP2 支持中文查询。

3. 搜索与矩阵运算

GPU 矩阵运算: similarities = logit_scale x batch_vectors @ all_features_gpu.T batch_vectors: (12500, 768) ← 所有 prompt 的 FP16 向量 all_features_gpu: (Sx3, 768) ← 所有场景的 3 帧 FP16 特征 similarities: (12500, Sx3) ← 每个 prompt x 每个场景帧

每个场景的 ~12,500 个 prompt 候选按 category (主体/动作/场景/情绪) 分组，每类取最高分：

scene_001 → 主体: "男人" (sim=80) ← result:scene_001_主体 scene_001 → 动作: "奔跑" (sim=90) ← result:scene_001_动作 scene_001 → 场景: "城市" (sim=50) ← result:scene_001_场景 scene_001 → 情绪: "悲伤" (sim=60) ← result:scene_001_情绪

4. 交集过滤

场景必须命中 必有标签 中配置的 全部 4 个类别，否则丢弃：

if len(cat_idx_map) >= 2: 按 scene_base 分组 → 所有类别都命中 → 合并标签 → 写入新 LMDB else: 跳过交集过滤 凑不齐 4 类 → 返回空结果 (不输出单标签)
FG-CLIP2 注意事项：FG-CLIP2 对场景/情绪类别的余弦相似度天然偏低，阈值 14 时可能凑不齐 4 类 → 无输出。建议 FG-CLIP2 阈值调为 8-10，或在交集过滤后启用 MiniCPM 验证补充。

5. MiniCPM 标签验证与剥离

流程

1
抽帧 (decord) → LabelVerifier.verify(frame, labels) → MiniCPM 判断每类标签真/假
2
匹配数 >= mini_rerank_min_matches → 保留场景；小于 → 删除场景
3
标签剥离: MiniCPM 判定为否的标签 → 从 LMDB item 中删除 xxx_cn/_en + 清理 labels/all_labels → 重建 result_name → 写回 LMDB
4
MiniCPM 解析失败 → ValueError 直接冒泡 → 管道终止 (不吞错)

效果

场景MiniCPM 判定结果
"男人"在"奔跑"，"城市"，"恐怖"主体:Y 动作:Y 场景:Y 情绪:N匹配 3/4 → 保留 → 剥掉"情绪"标签 → 视频名: 城市_男人_奔跑_1234_xxx.mp4
"宝石"在"演奏"主体:Y 动作:Y 场景:N 情绪:N匹配 2/4 → 低于 min_matches →删除
min_matches 建议: 4 个必有标签时设 3 (允许缺 1 类)；严格模式设 4 (全部命中)

6. 视频导出

命名格式从 输出视频命名格式 读取: {情绪}_{场景}_{主体}_{动作}_{起始帧}_{视频解析名}

各占位符从 item 的 _cn 字段动态填充。标签剥离后的 item 自动排除被删标签，视频名相应收缩。

完整: 绝望_赛博空间_宝石_演奏_1008_xxx.mp4 剥情绪: 赛博空间_宝石_演奏_1008_xxx.mp4 (情绪被 MiniCPM 判否 → 从文件名消失)

勾选 输出相似度 时前缀加分数: 21.3400_绝望_赛博空间_宝石_演奏_1008_xxx.mp4

9. 添加/删除/修改标签指南

操作方法
添加新孙类标签在对应子类 JSON 中加 "中文": "english"，代码自动纳入模板
添加新子类在 标签.大类 下加子类字典，模板中用 {子类名} 占位符
添加新大类在 标签、自动提纯prompt、必有标签 三处同步添加
修改命名格式改 输出视频命名格式 值，占位符自动匹配
