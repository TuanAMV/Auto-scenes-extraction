2. Prompt 生成

从 logic_keywords.json 读取 4 大类模板，每类独立生成 prompt (非笛卡尔积)：

类别模板生成 prompt 数
主体一张以{主体}为主体的动画风格插画~192
动作一张{生物}在{动作}的... + 一张{物体}在{物理运动}的...~12,224
场景一张以{所有场景}为背景的...~48
情绪一张有{所有情绪}氛围的...~37
合计~12,500
使用 use_chinese=False 时走英文模板 + 英文标签值，use_chinese=True 走中文。FG-CLIP2 支持中文查询。

3. 搜索与矩阵运算

GPU 矩阵运算: similarities = logit_scale x batch_vectors @ feature_tile.T batch_vectors: (B, D) ← 本批 B 条 prompt，D 为特征维度 feature_tile: (V, D) ← 当前向量块，V 受每批场景数限制 similarities: (B, V) ← 每条 prompt 对每个场景帧的分数

每个场景的 ~12,500 个 prompt 候选按 category (主体/动作/场景/情绪) 分组，每类取最高分：

scene_001 → 主体: "男人" (sim=80) ← result:scene_001_主体 scene_001 → 动作: "奔跑" (sim=90) ← result:scene_001_动作 scene_001 → 场景: "城市" (sim=50) ← result:scene_001_场景 scene_001 → 情绪: "悲伤" (sim=60) ← result:scene_001_情绪

4. 交集过滤

场景必须命中 必有标签 中配置的 全部 4 个类别，否则丢弃：

LMDB 分组 Top-K → 按视频与帧区间聚合 → 检查必有类别、子类和标签 → 写入结果库
交集过滤先于 Jev-rerank。没有通过 CLIP 必有类别筛选的镜头不会进入模型核验。本次显式传入的 search_threshold 优先。网页提交 CLIP、FG-CLIP2 两个阈值，搜索按选中的 Lance 模型取值；未指定时才读取 config.json。

5. Jev-rerank 与美学评分

原 MiniCPM 重排已替换为 VideoJev-4B。两个开关默认关闭，按需启动项目内 python/python.exe 的子进程。取合并后场景原始起止帧的中点，向下取整。每张图片编码一次，同时勾选时复用视觉特征。

只勾美学时直接计算 0–100 分，保留召回的标签和相似度。两项同开时，只有达到最低匹配数才计算美学分。关闭美学时不会构造或发送美学问题。

勾选标签验证时

1
抽帧 (decord) → JevReranker.evaluate(中间帧, 标签问题) → “是”的概率 ≥ 0.5 计为该类别匹配
2
匹配数 >= jev_rerank_min_matches → 保留场景；小于 → 删除场景
3
标签剥离: Jev-rerank 判定为否的标签 → 从 LMDB item 中删除 xxx_cn/_en + 清理 labels/all_labels → 重建 result_name → 写回 LMDB
4
Jev-rerank 推理失败会报告错误并终止本次任务

最低匹配数设为 3 的例子（默认 4）

场景Jev-rerank 判定结果
"男人"在"奔跑"，"城市"，"恐怖"主体:Y 动作:Y 场景:Y 情绪:N匹配 3/4 → 保留 → 剥掉"情绪"标签 → 视频名: 城市_男人_奔跑_1234_xxx.mp4
"宝石"在"演奏"主体:Y 动作:Y 场景:N 情绪:N匹配 2/4 → 低于 min_matches →删除
min_matches 建议: 4 个必有标签时设 3 (允许缺 1 类)；严格模式设 4 (全部命中)

6. 视频导出

导出文件名使用 logic_keywords.json 中的 其他参数设置 → 输出视频命名格式。当前设置为 {情绪}_{场景}_{主体}_{动作}_{起始帧}_{视频解析名}

各占位符从 item 的 _cn 字段动态填充。标签剥离后的 item 自动排除被删标签，视频名相应收缩。

完整: 绝望_赛博空间_宝石_演奏_1008_xxx.mp4 剥情绪: 赛博空间_宝石_演奏_1008_xxx.mp4 (情绪被 Jev-rerank 判否 → 从文件名消失)

只勾选输出相似度时，保留原前缀 21.3400_原名.mp4。再勾选美学评分后为 21.3400_81.50_原名.mp4。单独输出美学为 81.50_原名.mp4。已请求评分但抽帧失败时，评分位置写 未评分

Reranker 帧缓存temp/cache/jev_rerank/图片文件每个窗口处理完成后清除 JPG

单个 Lance 也按行分批读取。提示词分批与场景向量块相乘，类别最高分和断点按批次写入 LMDB。全局排序使用 LMDB 固定宽度索引键的有序游标，结果按批传给后处理和导出；任务成功后清理中间状态库。

12. 代码审查记录 · 2026-11-27

核对范围为自动提纯网页、调度入口、搜索引擎与仓内调用方。预设统一使用 Jev-rerank 字段。

对照百度网盘下载目录中的改动前副本，下面列出的三个批搜索方法和两个抽帧缓存方法在旧项目内也只查到定义；旧版自动提纯的图像问答重排确有被调用。旧版入口曾覆盖用户指定的搜索阈值。现在显式搜索阈值优先；命名统一由词库控制。

实现原本用途与实际状态
搜索配置摘要与全量结果字典已移除旧版无人读取的配置摘要及全量字典接口。断点续跑从 checkpoint 校验配置哈希并恢复进度。合并、核验和导出通过 iter_batches() 分批读取最终结果。
共享抽帧器的 _clear_cache_dir() 和 get_cache_stats()_clear_cache_dir() 清除持久帧文件；get_cache_stats() 查询实例计数与目录。旧版仓内没有调用点。本次增加显式清缓存入口：TextSearch 清理会调用新增的公开 clear_cache_dir()；Jev 单图推理使用任务专属临时目录，退出时清理。
搜索阈值与导出命名显式阈值直达批搜索。未指定时按当前 Lance 的模型读取网页值或配置。每次搜索从词库读取命名模板，标签合并、相邻合并和 Jev 剥除标签后都使用同一模板。导出时可在结果名前加评分、景别和运动标签。

本地 VideoJev 权重位于 models/MCG-NJU--VideoJev-4B/snapshots/master。同一次任务复用一个模型进程。标签复核开启时，读不到指定帧会记录并淘汰该条。单独开启美学时保留该条并标为“未评分”。导出与 FFmpeg 抽帧共用 models/ffmpeg/bin。
