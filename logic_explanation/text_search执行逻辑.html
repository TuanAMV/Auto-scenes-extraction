text_search 执行逻辑

代码依据: text_search.py + Frame_text_search.html  |  单文本语义搜索  |  全链路 FP16

1. 请求链路

1
前端 Frame_text_search.html → 用户输入文本 + 选择 Lance 索引 → 点击搜索
2
前端 POST /search → JSON 体含 query, indices, threshold, 重排/去重参数
3
后端 search_similar_scenes() → 参数校验 → 多索引模型一致性检查 → 文本召回 → 可选重排/去重
4
返回 JSON → 前端渲染缩略图 → 用户可预览(/get_preview)、导出(/export_clips)

2. 搜索执行流程

1
读取 request.json，校验 query 和 indices 非空
2
解析参数: threshold (默认 20.0), use_fp16 (FP16 全链路固定生效), 重排/去重参数
3
模型名提取: 从 Lance 目录名提取模型名，多索引要求同一模型，否则 400
4
模型加载/复用: get_or_create_processor() 创建 EmbeddingModelProcessor + SemanticSearchEngine，模型切换时自动释放旧模型
5
初筛召回: 遍历每个 Lance 索引 → search_engine.search_by_text(...) 做 CLIP 余弦相似度搜索
6
可选重排: Reranker 启用时先释放 CLIP 显存 → 加载 Qwen3-VL-Reranker → 前 rerank_top_k 条重打分 → 融合分数 → 释放 Reranker
7
最终过滤: similarity >= threshold
8
可选去重: 按 Lance 分组加载场景向量 → 余弦相似度去重 → OP/ED 优先保留

6. 重排公式

final_score = CLIP_sim x (1 - rerank_weight) + rerank_score x 100.0 x rerank_weight

步骤: 1) 取初筛前 rerank_top_k 条 → 2) 批量抽取帧 → 3) Reranker 打分 → 4) 融合排序 → 5) 释放 Reranker 模型

7. 搜索引擎

  1. Lance 直读: 直接从 Lance 索引读取 FP16 特征向量，无需 NPZ 缓存层
  2. 文本编码: 查询文本 → CLIP/FG-CLIP2 → L2 归一化向量
  3. 相似度计算: logit_scale * query @ image_features.T
  4. logit_scale: OpenAI CLIP ≈ 100 (logit_scale.exp()); FG-CLIP2 用相同 100.0 硬编码

8. 返回结构

字段说明
