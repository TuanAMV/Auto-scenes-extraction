1. 请求链路

1
前端 Frame_text_search.html → 用户输入文本 + 选择 Lance 索引 → 点击搜索
2
前端 POST /search → JSON 体含 query, indices, threshold, 重排/去重参数
3
后端 search_similar_scenes() → 参数校验 → 多索引模型一致性检查 → 文本召回 → 可选 Jev-rerank、美学评分及去重
4
返回 JSON → 前端渲染缩略图 → 用户可预览(/get_preview)、导出(/export_clips)

2. 搜索执行流程

1
读取 request.json，校验 query 和 indices 非空
2
解析参数: threshold (默认 20.0), use_fp16 (加载检索模型时使用，API 缺省 False), 重排/去重参数
3
模型名提取: 从 Lance 目录名提取模型名，多索引要求同一模型，否则 400
4
模型加载/复用: get_or_create_processor() 创建 EmbeddingModelProcessor + SemanticSearchEngine，模型切换时自动释放旧模型
5
初筛召回: 遍历每个 Lance 索引 → search_engine.iter_text_matches(...) 做 CLIP 余弦相似度搜索
6
可选 Jev-rerank: 启用时先释放 CLIP 显存 → 加载 VideoJev-4B → 前 jev_rerank_top_k 条验证 → 分数 ≥ 阈值者保留并加分 → 释放 Jev-rerank
7
执行最终过滤： similarity >= threshold
8
可选去重: 按原始帧区间读取向量。同一 Lance 内先检查 OP/ED 优先规则，否则只比较不同视频。
9
片段边界：按网页设置调整保留片段的起止帧，供预览和导出使用。填 0 保留原始边界。

6. Jev-rerank、美学评分与命中帧

score >= jev_rerank_threshold → 保留；similarity += score * 50；随后再按 threshold 过滤

步骤: 1) 取初筛前 jev_rerank_top_k 条 → 2) 抽取 CLIP 最高分向量对应的原始帧 → 3) Jev-rerank 以“是”的概率打分 → 4) 低于阈值丢弃 → 5) 保留者加分并重新过滤

命中中间向量时优先使用索引记录的采样帧号。缺少帧号时，取原始起止帧号的平均值并向下取整，重排、美学评分和预览共用该帧。旧索引可直接搜索。实测原始镜头为第 357–402 帧时使用第 379 帧，即使展示区间偏移至第 353–408 帧，模型和预览仍使用第 379 帧。

原 MiniCPM 重排已替换为嵌入式 Python 中的 VideoJev-4B。两个开关可独立使用。只开美学时，对召回结果逐条评分，保留 CLIP 相似度和顺序；只开重排时只发送查询匹配问题；两项同开时编码同一张图，达到概率阈值才计算美学分。两个开关都关时不会加载 VideoJev。阈值过滤与可选去重仍在后续执行。

结果卡在相关度后显示美学总分（0–100）。带分导出为 64.1861_85.95_起始帧_解析名.mp4，未启用美学时沿用 起始帧_解析名.mp4。抽帧失败会保留原候选并注明原因，已勾选美学时显示“未评分”。

7. 搜索引擎

  1. Lance 直读: 直接从 Lance 索引读取 FP16 特征向量，无需 NPZ 缓存层
  2. 文本编码: 查询文本 → CLIP/FG-CLIP2 → L2 归一化向量
  3. 相似度计算: logit_scale * query @ image_features.T
  4. logit_scale: 优先读取模型的 logit_scale.exp()，缺少该属性时使用 100.0

10. 代码审查记录 · 2026-11-27

实现原本用途与实际状态
跨视频去重同一 Lance 内用原始区间查向量，经 OP/ED 优先规则处理后，普通场景仅在来自不同视频时互相比较。
getSelectedIndexPaths()、applySelectedIndices()用于预设迁移和复选：保存模型目录名及所选 Lance 文件名，加载时在本机重建实际路径再恢复多选；未找到的文件会提示。保存预设、恢复预设和提交搜索都有调用。

旧版在去重前修改帧区间，使用默认偏移时可能找不到索引里的向量。现在按原始区间完成去重，再对展示和导出使用的片段区间应用偏移。

对照百度网盘下载目录中的改动前副本，旧版也只调用跨视频去重；全场景去重函数和两个索引选择辅助函数当时只查到定义，本次已将索引辅助函数接入预设保存和恢复。旧版搜索有未使用的偏移量记录，现已移除。当前版本已删除会比较同一视频片段的旧辅助算法。

命中记录按批写入 LMDB，并通过固定宽度键对相似度、时长和时间建立有序索引；跨索引结果由游标流式排序。LMDB 映射初始为 16 MiB，数据需要时自动扩容。向量去重逐块读取当前场景与此前保留的其他视频场景。网页结果与候选栏每页 50 条，全选覆盖当前查询，导出按页读取候选；手动清理会删除 TextSearch 结果库和候选库。

本地 VideoJev 权重位于 models/MCG-NJU--VideoJev-4B/snapshots/master。同一次任务复用一个模型进程。标签复核开启时，读不到指定帧会记录并淘汰该条。单独开启美学时保留该条并标为“未评分”。导出与 FFmpeg 抽帧共用 models/ffmpeg/bin。

优先取命中向量对应的实际帧号。旧索引缺少帧号时，三向量按命中位置取原始起始帧、中点或结束帧，其他向量数取中点。帧偏移只调整导出区间。排序分为 CLIP 原分加上 50 倍的肯定答案概率，美学分单独记录。
