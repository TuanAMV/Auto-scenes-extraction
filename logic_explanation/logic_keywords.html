logic_keywords.json 设计原理与结构

视觉原型 + 物理逻辑约束  |  四大类标签树  |  自动提纯 prompt 模板

1. 设计哲学

抛弃关键词堆砌，采用"视觉原型 + 物理逻辑 + 介词流"的生成模式，确保每条 prompt 都符合物理常识且被 CLIP 模型准确理解。

三大原则

视觉原型化 — 将抽象概念映射为视觉特征明确的英文单词。社会身份归类为通用视觉词（如"警察"→ man），武器型号映射为形态词（如"步枪"→ gun）。
去时序化 — 剔除 CLIP 无法理解的剪辑概念（时间变化、转场、镜头拉伸），只保留强视觉特征的瞬间状态（如 burning、floating）。
物理逻辑约束 — 标签分属四大类，各自有不同的行为合法性：
类别示例允许的动作禁止的组合
生物/器官人、怪物、手、心脏情绪行为 + 姿态 + 运动 + 物理状态—
物体建筑、树木、武器、载具运动状态 + 物理状态情绪/生物行为（枪不会哭）
场景城市、森林、星空—（被动存在）—
情绪恐怖、浪漫、悲伤—（氛围定义）—

2. JSON 顶层结构

标签 — 标签树（四大类 + 子类 + 孙类）
主体 → 生物（男人/女人/怪物...）、物体（建筑/武器/载具...）
动作 → 生物行为（奔跑/战斗/哭泣...）、物理运动（燃烧/爆炸/飘动...）
场景 → 所有场景（城市/森林/星空...）
情绪 → 所有情绪（恐怖/浪漫/悲伤/希望...）
自动提纯prompt — 每大类的中/英文 prompt 模板
其他参数设置 — 输出命名格式、必有标签、MiniCPM 验证 prompt

3. 标签树三级结构

层级用途JSON 结构示例
大类模板分类键、交叉验证维度标签对象的一级 key"主体"、"动作"
子类物理逻辑分组大类 value 的二级 key"生物"、"物理运动"
孙类实际标签值子类 value 的键值对奔跑: "running"

格式规则

  • 孙类 = "中文键": "英文值;"。分号分隔的英文值已拆分为独立条目（v2026.06）。
  • 子类名如 生物行为 和 物理运动 仅为结构分组，不参与 prompt 填充。
  • 模板中的占位符 {生物}、{物理运动} 由代码从子类键名自动匹配。

4. 自动提纯 Prompt 模板

每个大类有对应模板，占位符 {子类名} 从标签树动态解析。当前使用"动画风格插画"统一主题。

类别模板 (zh → en)生成数
主体 一张以{主体}为主体的动画风格插画
→ An animated-style photo featuring a {主体} as the main subject		 ~192
动作 一张{生物}在{动作}的动画风格插画
→ An animated-style photo of a {生物} {动作}

一张{物体}在{物理运动}的动画风格插画
→ An animated-style photo of a {物体} {物理运动}		 ~12,224
场景 一张以{所有场景}为背景的动画风格插画
→ An animated-style photo with a {所有场景} backdrop		 ~48

合计~12,500
占位符解析规则：模板中 {生物} → 遍历标签树中 主体.生物 下的翁类（男人/女人/怪物...）；{动作} → 遍历 动作.生物行为 下翁类。一个模板可有多组占位符，各组笛卡尔积。

5. 其他参数设置

输出视频命名格式

{情绪}_{场景}_{主体}_{动作}_{起始帧}_{视频解析名}

各占位符从最终结果的 _cn 字段填充。MiniCPM 判否的标签被剥离后自动从文件名消失。

必有标签

["主体", "动作", "场景", "情绪"] — 场景必须同时命中这 4 个类别才通过交集过滤。可选 必有子类 / 必有孙类 做更严格约束。

MiniCPM 验证 Prompt

每个大类有专用验证句式，根据 use_chinese 选择中文或英文版：

类别中文验证句英文验证句
主体以{val}为主体a {val} as the main subject
动作主体正在{val}the subject is {val}
场景以{val}为背景with a {val} backdrop
情绪画面渲染{val}情绪with a {val} mood

MiniCPM 返回 JSON {"主体": "是", "动作": "否", ...}，解析后用于标签剥离（判否 → 从结果中删除）。

6. 修改与扩展指南

操作方法影响
添加翁类标签 在对应子类中加 "中文": "english" 自动纳入模板、prompt 总数增加、缓存自动失效
添加子类 在大类下加子类字典，模板中加对应占位符 需同步修改模板
添加大类 标签树 + 自动提纯prompt + 必有标签 三处同步 交集过滤要求同步更新
修改命名格式 改 输出视频命名格式 所有视频重命名
修改模板主题 改 自动提纯prompt 中/英文本 Prompt 缓存自动失效重建
